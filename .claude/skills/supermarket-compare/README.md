# כמה אתה משלם יותר בסופר

**צילמת קבלה מהסופר? תגלה כמה אותו סל היה עולה בסופרים סביבך.** סקיל ל-Claude Code שקורא את הקבלה, משווה כל מוצר מול קובצי המחירים והמבצעים הרשמיים של חמש רשתות גדולות, בכל הרדיוס שתבחר, כולל ירקות וביצים, ומראה כמה היית חוסך ואיפה.

![הקבלה נפרשת, כל שורה עפה לסניף על המפה והמונה רץ](assets/demo.gif)

| מה הוא עושה | מה מקבלים |
|---|---|
| קלוד קורא את הקבלה מהצילום | רשימת המוצרים, הכמויות והמחירים ששילמת, בלי מפתח API |
| מוריד את קובצי המחירים שהרשתות מחויבות לפרסם לפי חוק | מחיר ומבצעים לכל מוצר בשופרסל, רמי לוי, יוחננוף, אושר עד וקרפור |
| מתאים כל שורה לברקוד | השוואה של אותו מוצר בדיוק, לא "משהו דומה" |
| בודק את הסניפים ברדיוס שתבחר | כמה עולה הסל בכל סניף, כולל מבצעים פתוחים לכולם, ואיפה הכי זול |
| ממליץ על סניף אחד | שם, כתובת, ניווט ב-Waze או בגוגל מפות, וכמה נשאר אחרי עלות נסיעה משוערת. אם לא משתלם לזוז, הוא אומר להישאר |
| מכין את הקנייה הבאה | רשימת קניות לסניף, איפה רוב החיסכון, מה דווקא יקר יותר שם, ומתי שווה לעצור בשני סניפים |
| ממשק מונפש | הקבלה נפרשת, כל שורה עפה לסניף על מפה אמיתית, והמונה רץ. מצלמים את המסך ויש סרטון |

## התקנה

1. צריך [Claude Code](https://claude.com/claude-code) מותקן במחשב.
2. פותחים אותו ומדביקים:

> התקן לי את הסקיל "כמה אתה משלם יותר בסופר" מהכתובת https://github.com/Brain-ai-biz/supermarket-compare : הורד את הריפו לתיקיית הסקילים שלך, ~/.claude/skills/supermarket-compare (אם אין git במחשב, הורד את קובץ ה-zip של הריפו וחלץ אותו לשם). אחר כך הפעל את הסקיל, תסביר לי מה אתה עושה, ותוביל אותי צעד אחרי צעד להשוות קבלה מהסופר. דבר איתי בעברית.

3. מכאן קלוד מוביל: מכין את הסביבה, מבקש צילום של הקבלה, ומריץ.

## האם זה יעבוד אצלי?

- **מחשב:** נבדק על מק. כתוב גם לווינדוס ולינוקס, עם פייתון 3.10 ומעלה.
- **קבלה:** מכל אחת מחמש הרשתות. צילום ישר וחד של כל הקבלה.
- **עלות:** הסקיל חינם, קובצי המחירים והמפה ציבוריים, ואין מפתח API. צריך רק Claude Code.
- **פרטיות:** צילום הקבלה נשלח לקלוד, כמו כל קובץ שפותחים בשיחה. אם מודפסות עליה ספרות של כרטיס אשראי או שם מועדון, אפשר לכסות אותן לפני הצילום.

## כמה אפשר לסמוך על זה

**חשוב לדעת: המערכת עלולה לטעות ולא תמיד מדייקת ב-100%. היא נשענת על קובצי המחירים שהרשתות מפרסמות ועל קריאת הקבלה בידי AI, ומחירים, מבצעים, מלאי וכתובות יכולים להשתנות. זו הערכה ולא הבטחה לסכום בקופה, אז לפני נסיעה מיוחדת כדאי לוודא מול הסניף.**

**המקור:** הקבצים שהרשתות חייבות לפרסם לפי תקנות שקיפות המחירים, לכל סניף, כל יום. ההשוואה לפי ברקוד, כלומר אותו מוצר בדיוק.

**המגבלות:**
- המספר הראשי כולל מבצעים פתוחים לכולם. מועדון מוצג בנפרד, וקופונים ומבצעים מורכבים לא נספרים. אז בקופה זה יכול לצאת קצת אחרת.
- הקבצים לא מושלמים: הרשות להגנת הצרכן ציינה שהנתונים נשלחים לעיתים שגויים, ומוצר שרשת לא דיווחה עליו לא יופיע.
- ירקות, פירות וביצים מושווים לפי סוג ומחיר לק"ג, כי אין להם ברקוד משותף. זה שווה ערך, לא בהכרח אותה איכות, והכלי מציין בנפרד כמה מהסל זהה בברקוד.
- המרחק הוא בקו אווירי. סניף שלא אומת במפה מסומן.
- הסקיל מדפיס בכל הרצה בדיקת אמינות: כמה מהמחירים בקבלה שלך זהים לקובץ.

התייחסו לתוצאה כאל הערכה טובה מהדיווח הרשמי, לא כהבטחה לסכום בקופה.
